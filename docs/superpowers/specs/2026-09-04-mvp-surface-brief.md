# `/mvp` Surface Brief

- **Scope and mode:** `/mvp` campaign workspace; Operate.
- **Audience:** A marketer turning an advertising idea into reviewable campaign assets without specialist production knowledge.
- **Primary task:** Write one natural-language brief, compare generated copy, select the campaign message, and understand what step comes next.
- **Primary action:** Analyze the brief, then select one copy row.
- **Evidence and content:** Current campaign state, editable generated variants, mock-provider disclosure, version status, and downstream-reset warnings.
- **Constraints:** Preserve the workflow state machine, gateway boundary, persistence, keyboard access, and the existing application outside `/mvp`.
- **Direction:** User-pinned Vercel-inspired monochrome operations console built from shadcn/ui, with a ChatGPT-like collapsible campaign sidebar.
- **Memorable moment:** One free-form brief unlocks a precise copy table in the same workspace; selection visibly advances the phase without changing context.
- **Unresolved decisions:** None for this frontend review slice.
