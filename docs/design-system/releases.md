# Design system releases

## v0.1.0 — local v2 artifact

The local-only `brutalist-design-system` artifact exposes portable Basics, Components and UI Blocks with a stylesheet entry. It is private and has not been published. Verification currently covers TypeScript, unit behavior, production build and local library artifact generation.

The live application catalog remains a compatibility surface. The separate workbench is additive while its full registry, consumer-tarball proof, Storybook, browser accessibility and visual review gates are completed.
