# Application layout templates

No standalone shared application template is claimed yet. ConnectedStudio currently owns the app shell; TemplateLibrary is a feature page. Their proposed extraction is documented in the roadmap.

An AppShell template should accept navigation, context/header, content and feedback slots. It must not fetch campaigns or decide workflow eligibility. A gallery template should only emerge after two real pages share structure and behavior.

AnimatedBanner, banner manifests and brand systems are campaign artwork. They are not application layout templates. Pages and realistic examples remain outside reusable component exports.
